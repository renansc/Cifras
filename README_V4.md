# NanotechSoft-Cifras v4

Execute:

```bash
./gerar.sh
xdg-open saida/NanotechSoft-Cifras.html
```

A versão v4 adiciona:
- biblioteca central;
- vários repertórios;
- nova cifra manual;
- editar/excluir cifras;
- mesma cifra em vários repertórios;
- ordenar músicas com ↑/↓;
- modo palco anterior/próxima;
- anotações;
- backup completo de cifras, repertórios, ordem, anotações e configurações.

O `repertorio.txt` continua sendo a fonte inicial usada na geração. Depois disso, alterações feitas no HTML único são persistidas no navegador e devem ser protegidas com BACKUP.
